# 水晶進銷存系統

個人水晶商品進銷存管理系統。在自己電腦上執行，用瀏覽器操作，不需要網路也能使用。

---

## 第一次安裝（只需做一次）

### 步驟 1：安裝 Docker Desktop

1. 前往 [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)
2. 點擊「Download for Windows」下載並安裝
3. 安裝完成後**重新開機**
4. 開啟 Docker Desktop，等待左下角顯示綠色「Running」

### 步驟 2：設定密碼

1. 在系統資料夾中找到 `.env.example` 檔案
2. **複製**一份，更名為 `.env`（注意：是複製，不是移動）
3. 用記事本開啟 `.env`，修改以下兩行（設定自己的密碼，不要用預設值）：
   ```
   DB_ROOT_PASSWORD=【在這裡填入管理員密碼】
   DB_PASSWORD=【在這裡填入資料庫密碼】
   ```
4. 儲存並關閉

### 步驟 3：第一次啟動

雙擊 `start.bat`，等待系統下載並啟動（第一次約需 3–5 分鐘）。
啟動完成後會自動開啟瀏覽器。

---

## 日常使用

### 啟動系統
雙擊 **`start.bat`**
→ 系統啟動後會自動開啟瀏覽器，網址為 `http://localhost:3000`

### 關閉系統
雙擊 **`stop.bat`**（或直接關掉 Docker Desktop 也可以）

### 注意
- 使用系統前必須先確認 Docker Desktop 已開啟（工具列右下角有 Docker 圖示）
- 不用時可以執行 `stop.bat` 節省電腦資源

## 功能介紹

| 功能 | 說明 |
|---|---|
| 看板 | 一眼掌握庫存市值、已實現毛利、近期銷售 |
| 商品庫存 | 新增/編輯/刪除水晶商品，支援相片上傳、QR Code |
| 銷售紀錄 | 記錄每筆成交，自動計算毛利 |
| 分類管理 | 自訂水晶分類（如紫水晶、白水晶），影響 SKU 編號 |

### 商品狀態說明
- 🟢 **在庫**：現有庫存，可銷售
- 🟡 **預訂**：已被客人預訂，等待交貨
- ⚫ **已售出**：交易完成

### SKU 編號規則
系統自動產生，格式為 `分類代碼-年份-序號`，例如：
- `AM-2026-001`（紫水晶 Amethyst，2026年，第1件）
- `MW-2026-015`（月光石 Moonstone，2026年，第15件）

## 備份資料（重要！）

**強烈建議每週備份一次**，避免電腦故障導致資料遺失。

### 手動備份
雙擊 **`backup.bat`**，備份檔案會存到 `backups/` 資料夾中。

### 自動備份設定（建議）
1. 雙擊 **`install_scheduler.bat`**（以管理員身份執行）
2. 之後每天凌晨 2 點電腦開著時會自動備份

### 將備份同步到雲端（強烈建議）
將 `backups/` 資料夾移到 OneDrive 或 Google Drive 的同步資料夾中，
這樣備份檔案會自動上傳到雲端，硬碟壞掉也不怕。

---

## 資料還原

如果需要從備份還原，請聯絡設定此系統的人員，並提供 `backups/` 資料夾中最新的 `.sql` 檔案和 `photos_*` 資料夾。

## 常見問題

**Q：雙擊 start.bat 沒反應或出現錯誤？**
A：請先確認 Docker Desktop 已開啟且顯示綠色 Running。

**Q：瀏覽器打開是空白頁或連不上？**
A：系統可能還在啟動中，等約 15-30 秒後重新整理頁面。

**Q：相片上傳失敗？**
A：請確認圖片大小不超過 10MB，並使用 JPG、PNG 或 WebP 格式。

**Q：不小心刪錯銷售紀錄怎麼辦？**
A：刪除銷售紀錄後，商品狀態會自動恢復為「在庫」，不會影響商品資料。
